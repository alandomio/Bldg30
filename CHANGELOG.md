# Changelog

## 0.7.0 — 2026-10-24

- Show dashboard RAM as a percentage, with byte totals and swap details.
- Add clickable CPU, memory and GPU sorting, high-usage indicators and filtering.
- Explain CPU, RAM and GPU use in resource-specific overviews with app/helper rankings and process drill-down.
- Add a Disk page with bounded, cancellable scans, folder drill-down, largest files and Finder access. Mark inaccessible paths and incomplete totals explicitly.
- Add Services & ports with TCP listeners, bound UDP ports, process ownership and user/system launchd service states, including explicit disabled overrides.
- Make Claude quota freshness actionable with a connection guide and a read-latest-data action. Include expired windows in freshness status.
- Add saved Automatic, Italian and English interface language settings, including native menus and contextual guidance.
- Align application, protocol and Xcode version numbers. Add catalog validation and a guarded annotated-release-tag helper.

Previous releases are recorded in Git history and tags `v0.1.0` through `v0.6.0`.
